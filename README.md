# Aplicación móvil de figuras geométricas

###Descripción

Aplicación móvil desarrollada en Java para Android que permite visualizar de manera interactiva una secuencia de figuras geométricas con un número creciente de lados.

La aplicación permite al usuario avanzar por diferentes figuras y reiniciar la secuencia cuando lo desee.

###Funcionalidades

- Visualización de figuras geométricas mediante gráficos personalizados.
- Incremento progresivo del número de lados de las figuras.
- Interacción mediante controles de la aplicación.
- Opción para reiniciar la secuencia.
- Renderizado de las figuras directamente sobre un componente personalizado.

### Tecnologías y herramientas

- Java
- Android
 -Android SDK
 -Android Studio
 -Canvas
 -Paint
 -Path
 -AppCompat
 -Implementación

La aplicación utiliza las clases gráficas de Android para realizar el dibujo de las figuras.
Entre los principales componentes utilizados se encuentran:

- Canvas: utilizado para representar las figuras.
- Paint: utilizado para configurar las características de dibujo.
- Path: utilizado para definir las formas geométricas.
- View: utilizado para crear una vista personalizada para el renderizado.
- Button: utilizado para las acciones de interacción.

### Aprendizajes

Este proyecto permitió desarrollar conocimientos básicos de desarrollo de aplicaciones Android, programación en Java, manejo de vistas personalizadas y representación de gráficos mediante las herramientas proporcionadas por Android.
